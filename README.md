# Greedy Snake - Online Game Sync Framework

Greedy Snake 是一个基于 **TCP + Protocol Buffers (Protobuf)**
构建的在线游戏同步框架示例项目。\
项目以经典游戏 **贪吃蛇（Snake）** 为示例，演示了如何构建一个简单的
**实时网络同步游戏架构**。

该项目主要用于学习和实践以下内容：

-   TCP 长连接通信
-   Protobuf 高效数据序列化
-   实时游戏状态同步
-   客户端 / 服务端架构设计
-   网络游戏同步逻辑

项目适合用于 **网络游戏开发入门、实时同步框架学习、TCP通信实践**。

# 🏗 项目架构

    Client
       │
       │ TCP + Protobuf
       │
    Server
       │
       ├── 网络通信模块
       ├── 消息解析模块
       ├── 游戏逻辑模块
       └── 状态同步模块

整体流程：

1.  客户端建立 TCP 连接
2.  使用 Protobuf 编码发送消息
3.  服务器解析消息
4.  更新游戏状态
5.  广播同步给所有客户端

# 🚀 快速开始

## 1 克隆项目

``` bash
git clone https://github.com/DevilVoice/Greedy_Snake.git
```

## 2 进入项目

``` bash
cd Greedy_Snake
```

## 3 编译 protobuf

``` bash
protoc --java_out=./src message.proto
```

## 4 启动服务器

``` bash
java ServerMain
```

## 5 启动客户端

``` bash
java ClientMain
```

# 📡 网络协议

项目使用 **Protocol Buffers** 定义客户端与服务器之间的通信协议。

示例：

``` proto
message PlayerMove {
  int32 playerId = 1;
  int32 direction = 2;
}
```

客户端发送玩家操作：

    MOVE_UP
    MOVE_DOWN
    MOVE_LEFT
    MOVE_RIGHT

服务器处理后广播游戏状态。
